## 项目学习：self-lan-pan（CloudPan 自托管网盘）

**项目形态**：Go(Gin + GORM + glebarez/sqlite) 后端 + Vue 3 + TS + Vite + Pinia 前端；
前端产物经 `server/internal/web`（`go:embed all:dist`）打进单个 exe，无 Docker。
默认端口 18322；数据目录 `server/data`（env：`CP_DATA` / `CP_PORT` / `CP_PUBLIC_URL` / `CP_TRUSTED_PROXIES`）。

**重要：无 git 仓库**（`D:\sihuo-project\self-lan-pan\.git` 不存在）——改动前必须自行备份，没有版本回退兜底。

**规模**：49 个 `.go`、59 个 `.vue`、29 个 `.ts`（不含 node_modules）。
最大的文件：`web/src/apps/Explorer.vue`(107KB)、`AdminConsole.vue`(78KB)、`server/internal/handler/fs.go`(52KB)。

**关键分层与扩展点**
- `server/internal/handler/router.go` —— 唯一路由装配点（公开 / 需登录 / 内置浏览器代理 / ONLYOFFICE 回调 / 管理端 5 个分组）。
- 中间件：`Auth` → `GuestReadOnly` → `AppGate(key)`（功能门控）→ `AdminOnly` / `RateLimit`；SSRF 三层防护在 `handler/ssrf.go`。
- **功能开关机制**：`server/internal/apps/manifest.go` 的 `Manifest`（15 个 key）为唯一清单；路由挂 `middleware.AppGate(key)`，前端 `stores/appstate.ts` 的 `isAvailable(key)` 控制入口显隐，`stores/apps.ts` 里 `APPS[].feature` 关联。新增/删除功能要同时动这三处。
- **存储抽象**：`fscore`（Driver 接口 + 注册表，`main.go` 里 `RegisterDriver`）→ `driver/{pan123,aliyun,baidu,tianyi}.go`；多用户按 `<策略根目录>/<用户目录名>` 隔离（`UserSetting(local_dir)` 固化）。
- **前端主题插件化**：`themes/{windows,macos,deepin}/index.ts` 各导出一个 `ThemeDef`（Boot/Login/Register/Lock/Desktop/WindowFrame + geometry/caption/snapEdges/wallpapers），在 `themes/registry.ts` 登记；同文件还有应用组件注册表 `APP_COMPONENTS`（app id → 懒加载 vue）。`shell/ShellHost.vue` 按 `session.osTheme` 动态解析主题。
- 路由（hash）：`/boot|/login|/register|/desktop` 走 `ShellHost`（props.screen 决定挂哪个主题组件）；`/s/:token` 公开分享页；`/office`、`/s/:token/office` 整页编辑器；`/app/:app` 独立单应用模式。

**构建链**：`build.bat` = `npm run build` → 拷 `web/dist` 到 `server/internal/web/dist` → `go build -o cloudpan.exe`。
当前 `web/node_modules`、`web/dist`、`server/cloudpan.exe`、`server/data` **均不存在**（尚未构建过）。
Go 1.27 位于 `C:\Program Files\Go\bin`；Node 用 workbuddy 托管版 22.22.2。
