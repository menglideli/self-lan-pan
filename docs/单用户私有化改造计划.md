## 2. 已实测确认的核心风险（含证据）

### 2.1 【已实测复现】游客 24h 清理任务会物理删除文件，且绕过回收站

**证据（改前基线，2026-09-11 实测）**：在挂载策略根下放一个 mtime 为 3 天前的文件，服务重启后该文件消失；同目录 24h 内的文件保留。

```
### 1. [改前] 初始文件清单（游客有效目录 = 策略根/guest）
-rw-r--r--  fresh.txt      (刚刚)
-rw-r--r--  old.txt        (2026-09-08 20:09，3 天前)
### 4. [改前] 重启后文件清单
-rw-r--r--  fresh.txt      ← 仅剩新文件
>>> 判定 A：old.txt 已被物理删除 → 危害复现（绕过回收站）
```

**机制**：`handler/tasks.go:70 sweepGuestWorkspace()` 每小时（且**服务每次启动时立刻执行一次**）遍历所有 `type=local status=active` 的策略，对游客身份解析出的物理根做递归 mtime 清理，`os.Remove` 直接物理删除，不进回收站。

**为什么会波及你的文件**：清理范围 = 游客身份在该策略下的有效根。

- 隔离**开启**时：有效根 = `<挂载根>/guest` → 目前只会删到游客自己的目录（所以现在还没伤到你）。
- 隔离**关闭**后：有效根 = `<挂载根>` → **清理范围直接变成你挂载的整个文件夹**。

> 这正是"关隔离"和"删游客"必须**同一批、且先删清理任务**的原因。顺序反了，一小时内就会丢数据。

### 2.2 【已确认】本地盘按用户子目录隔离，与"挂载即可见"直接冲突

```go
// server/main.go:26-32（webdav.go:52-59 有同一份）
root := p.RootPath
if dir := fscore.UserDirOf(u); dir != "" {
    root = filepath.Join(root, dir)   // 挂 E:\电影 → 实际访问 E:\电影\admin
}
```

改动点仅这两处 + `fscore.UserDirOf`（`local.go:319`，全仓只被这两处调用）。

### 2.3 挂载入口不在文件管理器里，且没有"选文件夹"能力

- 唯一入口：管理控制台 → 存储策略 → 挂载存储；"物理目录"是**纯文本框**（`AdminConsole.vue:668-671`）。
- 服务端**没有**列本机目录的接口（唯一的列目录端点是 SSH 远端的 `terminal/fs/list`）。
- 结论：**「分配菜单」是新增功能**，不是改造。

## 5. 批次 1 附带要处理的事：用户组删除后，那些"组参数"怎么办

删掉 `UserGroup` 后，原先从组里读的参数必须有固定值，否则会出现"读了空组 → 配额为 0 → 什么都传不上去"这类静默故障。预定固定值：

| 参数 | 原来源 | 固定值 |
| --- | --- | --- |
| 配额 | `UserGroup.QuotaMB` | **不限**（单用户内网，自己的盘） |
| 回收站保留天数 | `UserGroup.RecycleRetentionDays` | 30 天（保持现状语义） |
| 版本保留个数/天数 | `UserGroup.KeepVersions` / `VersionRetentionDays` | 维持现有默认值 |
| 允许分享/WebDAV/压缩/离线 | `Allow*` 系列 | 全部 `true` |
| 只读 | `ReadOnly` | `false` |
| 应用权限 | `AppPerms` | 全部开启（等价于管理员） |

> ⚠️ 这一项的影响面比"删两个路由"大得多：`fscore/service.go`、`fscore/versions.go`、`middleware/auth.go`、`handler/fs.go`、`bt.go`、`share.go`、`tasks.go` 都读组参数。我会在**批次 2** 单独做，并配"配额不限制 / 上传下载正常"的实测。

## 8. 安全承诺

- 不碰 `server/data/`（数据库/密钥/回收站），不动你已挂载的真实目录内容。
- 数据库只做 AutoMigrate 加表/加列；**不自动删列**，需要时单独提确认。
- 对外接口契约不变：端口 `18322`、`CP_PORT`/`CP_DATA`/`CP_PUBLIC_URL`/`CP_TRUSTED_PROXIES`、`build.bat`/`start.bat` 用法。
- 每批改完提交一次 git，保证可回退。
